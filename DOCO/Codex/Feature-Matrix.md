# Windows iAMP feature and acceptance matrix

Reconciled 18 October 2026 for **1.44.0**. Current support is summarized in [Current-Status.md](Current-Status.md), tasks in [Plan.md](Plan.md), and completed P5.8 acceptance in [Musician-Workflow.md](Musician-Workflow.md).

**I** means implemented with affected software checks. **H** records bounded device acceptance for that row, not every fault/combination or final release approval; N/A identifies a local-only feature. An implemented row can have open broader acceptance. Historical narrow proofs are in a separate table below and do not restrict current controls. Test counts refer to their dated runs, not a new complete-suite run.

Sources: M is the supplied manual's printed page (PDF offset +3 in referenced sections); A is retained artifact evidence; R is protocol/native/feature documentation and sanitized fixtures; W is private Windows device evidence. Supplied APK 1.6.1/code 42 differs from phone 1.6.1/code 43 despite shared publisher identity. Device data/captures stay private. Current live-control proofs target F15i V1.1.9; earlier V1.1.2 reads remain historical.
